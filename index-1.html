Google sign-in with a CKB wallet, backend and frontend

Let people sign in with Google and get a CKB wallet without installing anything. Google proves who they are, your server holds an encrypted CKB key for them, and CCC builds and signs the transactions. This is how Corven does it, in a NestJS/Node backend and a React frontend.

How it works 1. Google setup 2. Database 3. Verify Google 4. Encrypt keys 5. Create wallets 6. API routes 7. Frontend button 8. CCC signer Security Run it

How it works

CCC itself has no social login: its connector only lists wallets (JoyID, MetaMask, UniSat…). Social login is your own auth, with a wallet attached:

1. Google buttonGoogle Identity Services shows the account picker and returns a signed ID token.
2. Your API verifies itSignature, audience (your client ID), expiry, verified email.
3. Account + walletsFirst sign-in creates the user and a testnet and a mainnet CKB key, encrypted.
4. SessionYour normal access and refresh tokens. No Google token is stored.
5. TransactionsThe browser builds with CCC; the server decrypts the key only to sign.
Custodial. Your server holds the keys, so you are responsible for the funds. Keep mainnet limited, protect the master key, and let users export their key.

2Database (Prisma)

Store the Google account id (sub), never the Google token. One wallet per user per network, with the key encrypted.

prisma/schema.prisma
enum AuthProvider { EMAIL  CKB_WALLET  GOOGLE }
enum WalletNetwork { TESTNET  MAINNET }

model User {
  id            String       @id @default(uuid())
  name          String
  email         String?      @unique
  googleId      String?      @unique   // ID token "sub": stable, unlike email
  authProvider  AuthProvider @default(EMAIL)
  wallets       UserWallet[]
  createdAt     DateTime     @default(now())
}

model UserWallet {
  id             String        @id @default(uuid())
  userId         String
  user           User          @relation(fields: [userId], references: [id], onDelete: Cascade)
  network        WalletNetwork
  address        String
  publicKey      String        // compressed secp256k1, safe to share
  encryptedKey   String        // AES-256-GCM(private key, data key)
  wrappedDataKey String        // AES-256-GCM(data key, master key)
  keyVersion     Int           @default(1)
  createdAt      DateTime      @default(now())
  @@unique([userId, network])
}

3Backend: verify the Google token

verifyIdToken checks Google's signature, the issuer, the expiry and that the token was issued for your client ID. A token from another site is rejected.

auth/google-verification.ts
import { OAuth2Client } from 'google-auth-library';

const google = new OAuth2Client();

export async function verifyGoogleCredential(credential: string) {
  const clientIds = (process.env.GOOGLE_CLIENT_ID ?? '').split(',').map((s) => s.trim()).filter(Boolean);
  if (!clientIds.length) throw new Error('GOOGLE_CLIENT_ID is not set');

  const ticket = await google.verifyIdToken({ idToken: credential, audience: clientIds });
  const p = ticket.getPayload();
  if (!p?.sub || !p.email) throw new Error('invalid token');
  if (p.email_verified !== true) throw new Error('email not verified');

  return { sub: p.sub, email: p.email.toLowerCase(), name: p.name ?? null, issuedAt: p.iat ?? 0 };
}
auth/auth.service.ts
async googleLogin(credential: string) {
  const id = await verifyGoogleCredential(credential);   // throws -> 401

  let user = await prisma.user.findUnique({ where: { googleId: id.sub } });
  if (!user) {
    // Don't merge into an existing email/password account: if sign-up
    // doesn't verify emails, someone could pre-register a victim's address.
    if (await prisma.user.findUnique({ where: { email: id.email } })) {
      throw new ConflictException('An account with this email already exists.');
    }
    user = await prisma.user.create({
      data: { name: id.name ?? id.email.split('@')[0], email: id.email, googleId: id.sub, authProvider: 'GOOGLE' },
    });
  }

  await wallets.ensureWallets(user.id);   // step 5 (best effort)
  return issueSession(user);              // your existing access + refresh tokens
}

4Backend: encrypt the keys (envelope encryption)

Each private key is encrypted with its own random data key; the data key is encrypted with the master key from WALLET_ENCRYPTION_KEY. GCM's associated data binds each ciphertext to its user, network and address, so a copied row won't decrypt. Moving the master key into AWS KMS later only changes the wrap/unwrap step.

wallets/wallet-vault.ts
import { createCipheriv, createDecipheriv, randomBytes } from 'node:crypto';

const master = Buffer.from(process.env.WALLET_ENCRYPTION_KEY!, 'base64'); // 32 bytes

function seal(key: Buffer, data: Buffer, aad: string) {
  const iv = randomBytes(12);
  const c = createCipheriv('aes-256-gcm', key, iv);
  c.setAAD(Buffer.from(aad));
  const body = Buffer.concat([c.update(data), c.final()]);
  return Buffer.concat([iv, c.getAuthTag(), body]).toString('base64');
}

function open(key: Buffer, sealed: string, aad: string) {
  const raw = Buffer.from(sealed, 'base64');
  const d = createDecipheriv('aes-256-gcm', key, raw.subarray(0, 12));
  d.setAAD(Buffer.from(aad));
  d.setAuthTag(raw.subarray(12, 28));
  return Buffer.concat([d.update(raw.subarray(28)), d.final()]); // throws if tampered
}

const aadFor = (w: { userId: string; network: string; address: string }, part: string) =>
  `wallet:v1:${part}:${w.userId}:${w.network}:${w.address}`;

export function sealKey(privateKey: Buffer, w: { userId: string; network: string; address: string }) {
  const dataKey = randomBytes(32);
  try {
    return {
      encryptedKey: seal(dataKey, privateKey, aadFor(w, 'key')),
      wrappedDataKey: seal(master, dataKey, aadFor(w, 'data-key')),
    };
  } finally { dataKey.fill(0); }
}

/** Decrypts, runs `use`, wipes. Keep `use` short: sign and return. */
export async function withPrivateKey<T>(row: any, use: (hex: string) => Promise<T>) {
  const dataKey = open(master, row.wrappedDataKey, aadFor(row, 'data-key'));
  const key = open(dataKey, row.encryptedKey, aadFor(row, 'key'));
  try { return await use(`0x${key.toString('hex')}`); }
  finally { dataKey.fill(0); key.fill(0); }
}

5Backend: create wallets and sign with CCC

wallets/wallet.service.ts
import { ccc } from '@ckb-ccc/core';
import { randomBytes } from 'node:crypto';

const clientFor = (n: 'TESTNET' | 'MAINNET') =>
  n === 'MAINNET' ? new ccc.ClientPublicMainnet() : new ccc.ClientPublicTestnet();

export async function ensureWallets(userId: string) {
  for (const network of ['TESTNET', 'MAINNET'] as const) {
    if (await prisma.userWallet.findUnique({ where: { userId_network: { userId, network } } })) continue;

    const privateKey = randomBytes(32);                      // separate key per network
    const signer = new ccc.SignerCkbPrivateKey(clientFor(network), privateKey);
    const address = await signer.getRecommendedAddress();    // ckt1… / ckb1…
    try {
      await prisma.userWallet.create({
        data: { userId, network, address, publicKey: signer.publicKey,
                ...sealKey(privateKey, { userId, network, address }) },
      });
    } finally { privateKey.fill(0); }
  }
}

// Send CKB: the server builds the transaction itself (used for mainnet).
export async function transfer(userId: string, network: 'TESTNET' | 'MAINNET', to: string, amountCkb: string) {
  const row = await prisma.userWallet.findUniqueOrThrow({ where: { userId_network: { userId, network } } });
  const client = clientFor(network);
  const { script } = await ccc.Address.fromString(to, client);   // rejects wrong-network prefix

  return withPrivateKey(row, async (key) => {
    const signer = new ccc.SignerCkbPrivateKey(client, key);
    const tx = ccc.Transaction.from({
      outputs: [{ lock: script, capacity: ccc.fixedPointFrom(amountCkb) }],  // ≥ 61 CKB
      outputsData: ['0x'],
    });
    await tx.completeInputsByCapacity(signer);
    await tx.completeFeeBy(signer);
    return signer.sendTransaction(tx);
  });
}

// Sign a transaction the browser built (e.g. a contract deploy). Testnet only.
export async function signTestnet(userId: string, txJson: unknown) {
  const row = await prisma.userWallet.findUniqueOrThrow({ where: { userId_network: { userId, network: 'TESTNET' } } });
  const tx = ccc.Transaction.from(txJson as ccc.TransactionLike);
  return withPrivateKey(row, async (key) => {
    const signed = await new ccc.SignerCkbPrivateKey(clientFor('TESTNET'), key).signOnlyTransaction(tx);
    return JSON.parse(ccc.stringify(signed));
  });
}

6Backend: API routes

RouteDoesGuard
POST /auth/googleVerify the credential, find or create the user, start a sessionRate limit, trusted origin
GET /walletAddresses, public keys, balances. Never key materialSigned in
POST /wallet/transferSend CKB (server-built transaction)Mainnet: fresh Google confirmation + daily limit
POST /wallet/sign-testnetSign a browser-built testnet transactionTestnet only; refuse if it spends nothing of the wallet
POST /wallet/exportReturn the private key so the user can leaveFresh Google confirmation, Cache-Control: no-store

Fresh Google confirmation = the client sends a new Google ID token; the server verifies it, checks sub equals the user's googleId and that iat is under 5 minutes old. A stolen session token alone then can't move mainnet funds.

wallets/confirm.ts
async function confirmWithGoogle(userId: string, credential?: string) {
  if (!credential) throw new UnauthorizedException('Confirm with Google to continue.');
  const user = await prisma.user.findUnique({ where: { id: userId } });
  const id = await verifyGoogleCredential(credential);
  if (id.sub !== user?.googleId) throw new UnauthorizedException('Use the Google account you signed in with.');
  if (Date.now() / 1000 - id.issuedAt > 300) throw new UnauthorizedException('Confirmation too old.');
}

7Frontend: the Google button

Load Google Identity Services once, render its button, and post the credential to your API. The same component works for the mainnet "confirm with Google" step.

auth/GoogleSignInButton.tsx
import { useEffect, useRef } from 'react';

const CLIENT_ID = import.meta.env.VITE_GOOGLE_CLIENT_ID as string;
let loading: Promise<any> | null = null;

function loadGis() {
  if ((window as any).google?.accounts?.id) return Promise.resolve((window as any).google);
  return (loading ??= new Promise((resolve, reject) => {
    const s = document.createElement('script');
    s.src = 'https://accounts.google.com/gsi/client';
    s.async = true;
    s.onload = () => resolve((window as any).google);
    s.onerror = () => { loading = null; reject(new Error("Couldn't load Google")); };
    document.head.appendChild(s);
  }));
}

export function GoogleSignInButton({ onCredential }: { onCredential: (c: string) => void }) {
  const el = useRef<HTMLDivElement>(null);
  const cb = useRef(onCredential);
  cb.current = onCredential;

  useEffect(() => {
    if (!CLIENT_ID) return;
    loadGis().then((google) => {
      google.accounts.id.initialize({
        client_id: CLIENT_ID,
        ux_mode: 'popup',
        callback: (r: { credential?: string }) => r.credential && cb.current(r.credential),
      });
      google.accounts.id.renderButton(el.current!, {
        theme: 'filled_black', size: 'large', text: 'continue_with',
        width: Math.min(400, el.current!.offsetWidth),
      });
    });
  }, []);

  return CLIENT_ID ? <div ref={el} style={{ width: '100%', minHeight: 44 }} /> : null;
}

8Frontend: a CCC signer backed by your server

Extend CCC's public-key signer: CCC builds and prepares transactions in the browser as usual, but signing calls your API. Plug it in anywhere a CCC signer goes (deploy, transfer, dApp code).

wallet/server-signer.ts
import { ccc } from '@ckb-ccc/connector-react';

export class ServerTestnetSigner extends ccc.SignerCkbPublicKey {
  async signOnlyTransaction(txLike: ccc.TransactionLike): Promise<ccc.Transaction> {
    const tx = ccc.Transaction.from(txLike);
    const res = await api('/wallet/sign-testnet', {
      method: 'POST',
      body: JSON.stringify({ transaction: JSON.parse(ccc.stringify(tx)) }),
    });
    return ccc.Transaction.from(res);
  }
}

// Usage: publicKey comes from GET /wallet
const signer = new ServerTestnetSigner(new ccc.ClientPublicTestnet(), wallet.publicKey);
const tx = ccc.Transaction.from({ outputs: [{ lock }], outputsData: ['0x'] });
await tx.completeInputsByCapacity(signer);
await tx.completeFeeBy(signer);
const hash = await signer.sendTransaction(tx);   // prepares, asks your server to sign, broadcasts
Prefer a connected wallet when the user has one: const signer = ccc.useSigner() ?? serverSigner;

Security checklist

  • Verify every ID token on the server, with your client ID as the audience. Never trust a decoded token from the browser.
  • Match users by Google sub, not email; only accept email_verified.
  • Don't auto-merge Google sign-ins into existing unverified email accounts.
  • Never return or log encrypted keys or plaintext keys (except the explicit export).
  • Mainnet: server-built transactions only, a fresh Google confirmation, and a daily limit.
  • Back up WALLET_ENCRYPTION_KEY off the server. Losing it loses every wallet; changing it breaks them.
  • The master key and the database on one server means a full server compromise exposes both. Move the master key to a KMS (e.g. AWS KMS) before real value builds up.
  • Let users export their key, and check the legal side of holding users' funds where you operate.
